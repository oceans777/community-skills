# AGENTS.md

This repository stores third-party skills mirrored, adapted, or repackaged by oceans777.

## Rules

- Place each skill under `skills/<safe-skill-name>/`.
- Use lowercase letters, digits, and hyphens for skill names.
- Preserve upstream attribution.
- Every skill must include `UPSTREAM.md` and `PATCHES.md`.
- Keep the original license text or a clear license reference.
- Do not import content whose license does not permit redistribution.
- Record local modifications in `PATCHES.md`.
- Do not commit secrets, tokens, private paths, account details, or machine-specific configuration.
