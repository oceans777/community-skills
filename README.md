# oceans777 Community Skills

This repository contains third-party skills mirrored, adapted, or repackaged by oceans777.

Every skill must preserve source and license information.

Skills live under:

```text
skills/<safe-skill-name>/
```

Each community skill must include:

```text
SKILL.md
UPSTREAM.md
PATCHES.md
LICENSE
```

Use `gh-author-skill-name` when importing from GitHub.
